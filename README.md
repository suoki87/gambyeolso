## 구조

각 HTML 은 CSS·JS 를 전부 인라인한 단일 파일입니다. 외부 호스트 요청이 없습니다.

- 21문항 · 5점 리커트 · 3축
- 축마다 양극에 키된 문항(역문항)으로 묵종 편향 통제
- 8 캐릭터 · SVG 일러스트
- 친구 링크로 들어오면 두 유형의 궁합 표시

소스와 테스트는 별도 저장소에서 관리합니다. 이 저장소는 배포 산출물만 담습니다.
